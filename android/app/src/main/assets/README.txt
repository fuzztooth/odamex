ODAMEX WAD FILES DIRECTORY

Place your WAD files here before building the APK:

Required:
  - odamex.wad    (Build from wad/ directory or download from releases)

Game IWADs (at least one):
  - DOOM.WAD      (Shareware or registered DOOM)
  - DOOM2.WAD     (DOOM II)
  - FREEDOOM1.WAD (Free alternative)
  - FREEDOOM2.WAD (Free alternative)

Optional PWADs:
  - Any custom .wad files you want to include

How to get odamex.wad:
  1. Build it: cd to wad/ directory and run: deutex -make odamex.txt
  2. Download: Get from latest Odamex release on GitHub
  3. Copy: If you have Odamex installed, copy from installation directory

These files will be included in the APK and copied to device storage on first launch.

For testing without WADs, the app will run but won't be able to start a game.
